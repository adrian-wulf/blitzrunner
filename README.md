# RobinHood CI

**Zero-server, high-speed CI optimization suite under the RobinHood dev philosophy.**

Slashes CI/CD cloud costs by up to 90% and accelerates build times by 4x.

* 🛡️ **Smart Prune (`actions/smart-prune`):** Cuts up to 70% of unnecessary workflow runs in monorepos via intelligent `git diff` detection.
* ⚔️ **Ephemeral Cloud Runner (`actions/hetzner-runner`):** Replaces expensive, throttled 2-vCPU GitHub runners with disposable, 8-vCPU cloud beasts for pennies.
* 📊 **Scoreboard Summary:** Injects transparent cost-and-time savings directly into your GitHub Pull Request summaries.
